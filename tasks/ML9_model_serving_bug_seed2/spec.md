## Bugs in `serve.py`

### Bug 1: Wrong Channel Order

**Problem**: Training uses chw (channels first) but inference sends hwc (channels last)

**Fix**: Transpose input from HWC to CHW: x = x.transpose(2, 0, 1) or use np.transpose(x, (2,0,1)) before model input.

### Bug 2: Imagenet Stats Wrong

**Problem**: Inference uses [0,1] normalization but training used imagenet stats (mean=[0.485,0.456,0.406], std=[0.229,0.224,0.225])

**Fix**: Apply ImageNet normalization: (x/255.0 - mean) / std with mean=[0.485,0.456,0.406], std=[0.229,0.224,0.225] per channel.

### Bug 3: Missing Batch Dim

**Problem**: Inference passes single image without batch dimension (model expects batch)

**Fix**: Unsqueeze batch dimension: x = x[None, ...] or np.expand_dims(x, 0) to make shape (1, C, H, W).
