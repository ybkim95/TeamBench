## Bugs in `serve.py`

### Bug 1: Wrong Text Cleaning

**Problem**: Training lowercased and removed punctuation; inference does not lowercase

**Fix**: Apply text.lower() and re.sub(r'[^\w\s]', '', text) before tokenization, matching training.

### Bug 2: Tfidf Refit At Inference

**Problem**: Tf-idf vectorizer re-fitted on inference batch instead of using training vocabulary

**Fix**: Save the fitted TfidfVectorizer from training. Load and call .transform() (not .fit_transform()) at inference.

### Bug 3: Wrong Max Features

**Problem**: Inference tf-idf uses max_features=5000 but training used max_features=10000

**Fix**: Use the same TfidfVectorizer object from training (max_features=10000). Never re-configure at inference.
