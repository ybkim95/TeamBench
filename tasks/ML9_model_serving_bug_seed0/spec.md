## Bugs in `serve.py`

### Bug 1: Wrong Normalization Stats

**Problem**: Inference uses per-batch mean/std instead of training set statistics

**Fix**: Save and load train_mean and train_std from training. Apply: (x - train_mean) / train_std at inference.

### Bug 2: Missing Feature Clipping

**Problem**: Training clips features to [-3, 3] sigma but inference does not

**Fix**: Apply np.clip(normalized, -3, 3) after normalization, matching training preprocessing.

### Bug 3: Wrong Feature Order

**Problem**: Inference drops feature index 0 (thinking it's an id column) but training kept it

**Fix**: Do not drop any columns. Training used all {n_features} features.
